06 · Accounts

Add one. Fix one. Same button.

+ ADD ACCOUNT runs the real PKCE flow, the same one Claude Code runs. Browser opens, you approve, the token lands on your Mac. Nothing about it is a re-implementation with vibes.

  • Browser firstIt opens the Anthropic sign-in and waits on localhost:54545 for the callback. Use a browser signed into the account you actually want. A private window saves you a lot of grief.
  • Paste if it's weirdLocked-down network, odd default browser, localhost blocked by something with a compliance dashboard. Open the paste-mode link, copy the code#state string back into the box, hit USE.
  • It files itselfThe token gets saved under whichever account actually approved it, not the one you meant to pick. Sign in as Derek, you get Derek. No mislabeled rows.
  • Adding is repairingThe result is written in the CLI proxy's own file format, with tokens refreshed on the way through. So adding an account here quietly fixes a dead one for the proxy too.

The panel while it waits. Accounts list hides, footer stays. Cancel puts everything back.

When it works, four things move

02Claude Code-credentialsThe Keychain item Claude Code reads on its next turn.
03~/.claude.jsonoauthAccount, so the CLI agrees with the menu bar.
04*.sidestep-bakThe backup. Taken before any of the other three.

Three buttons. No settings window.

The bottom strip of the popover is the entire configuration surface of this app. Here it is at 1.6x so there's nowhere to hide.

01+ Add accountRuns the real PKCE flow. Browser out to Anthropic, callback back to localhost:54545, or paste code#state when localhost is being difficult. Tokens get refreshed on the way through and the result is written in the CLI proxy's own file format, which is why adding an account also repairs a dead one.
02Login itemLaunch at login, through the system API macOS gives you for exactly this. One checkbox. No plist to hand edit, no helper app hiding in your Library, no permission dialog that makes you feel watched.
03QuitQUIT quits. ⌘Q also quits. Revolutionary. Nothing keeps running after it, because there was never a background daemon to leave behind.
